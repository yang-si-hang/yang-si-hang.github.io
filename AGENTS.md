# Project Instructions

The project's customization tutorial is located at [`CUSTOMIZE.md`](CUSTOMIZE.md).

Before modifying the site's pages, navigation, content, layout, or configuration, consult `CUSTOMIZE.md` and follow the documented al-folio conventions whenever applicable.

## Commit requirement

Every feature change must be committed in Git before the work is considered complete. Keep each feature change in its own commit, and do not include unrelated existing work in that commit.
